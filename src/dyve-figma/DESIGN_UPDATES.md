# DYVE Design Update - Modern Color Scheme

## Color Changes
- Primary Red: `#FF2E2E` → `#FF3B5C` (More vibrant, modern neon pink-red)
- Hover Red: `#cc2525` → `#d43550` (Adjusted for new primary)
- Background Dark: `#1A1A1A` → `#0F0F0F` (Deeper black for more contrast)
- Gray Text: `#888888` → `#707070` (Better readability)

## Typography Improvements
- Headings: Increased font-weight to `extrabold` (800)
- Buttons: Changed to `font-bold` (700)
- Body text: Maintained at `font-medium` (600) and `font-normal` (400)
- Better letter-spacing for headings: `-0.02em` for h1, `-0.01em` for h2

## Visual Enhancements
- Added subtle shadows to accent elements: `shadow-lg shadow-[#FF3B5C]/20`
- Hover effects now include shadow animations
- Border radius increased to `1rem` (from `0.75rem`)
- Improved transition effects: `transition-all duration-300`
